# Contributing to `myTABs`

Thank you for helping improve this LoopLogic extension! Follow these rules:

## 📐 Code Standards
- Use React (function components + hooks)
- Tailwind for styling
- Follow modular design (one component = one file)
- Validate all changes locally before PR

## 🚧 Project Files
All new code must:
- Follow structure in `PLANNING.md`
- Be tracked in `TASK.md`
- Include doc updates in `README.md` if public-facing

## ✅ Workflow
1. Fork + branch from `main`
2. Add new task to `TASK.md`
3. Commit clearly + concisely
4. Submit PR with CI passing

---
LoopLogic CI will reject PRs missing critical files or test failures.
